{{ sample_manifest_json }}
Platzhalter in .env.example:
  • {% raw %}{{DB_NAME}}{% endraw %} : Automatischer Datenbankname
  • {% raw %}{{DB_USER}}{% endraw %} : Automatischer DB-Benutzer
  • {% raw %}{{DB_PASS}}{% endraw %} : Sicheres Zufalls-Passwort
  • {% raw %}{{DOMAIN}}{% endraw %} : Die gewählte Zieldomain
  • {% raw %}{{APP_KEY}}{% endraw %} : Generierter 32-Hex Secret Token
Automatisierte Schritte bei Deployment:
  • 1. Entpacken in /var/www/[domain]
  • 2. Optional: MySQL DB & User anlegen
  • 3. SQL Schema-Import (falls definiert)
  • 4. .env aus Template erzeugen
  • 5. Post-Install Commands (Composer, NPM)
  • 6. Berechtigungen auf www-data
